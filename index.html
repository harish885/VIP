The problem

The strategic intelligence gap.

SMEs have data. They lack the translation from data into a quantified compass for the decisions that actually matter — investment, exit, growth.

Data is everywhere

ERP systems, accounting software, CRMs — SMEs already produce more data than they realise. Storage isn't the constraint.

Insight is missing

Nobody translates that data into a clear picture of company value and the levers that drive it. Reporting describes; it doesn't decide.

Decisions in the dark

Investments, exits, growth bets — entrepreneurs commit capital and time without a quantified compass. Most rely on instinct, peer anecdotes, or one advisor's view.

What it must do

Five capabilities. One platform.

VIP isn't a research artefact. It's a working tool with five non-negotiable jobs — defined by the brief and reflected in every line of the model.

Valuation logic

One transparent formula. No black boxes.

Per-company value is built up from peer-relative scores across four capitals. Hover any variable to see what's behind it.

— core valuation formula —
V = EBITDA × Msector × SQF × GF
EBITDA
3-year normalised operating performance, smoothed for one-offs.
Msector
Sector multiple, adjusted for SME size and illiquidity.
SQF · 0.6–1.4
Strategic Quality Factor from the four-capital scoring.
GF · 0.7–1.5
Growth Factor — CAGR plus quality of growth.
Value Gap
The distance between today's value and the optimised potential the recommended actions could unlock. This is the platform's true differentiating insight.
Value Gap = Optimised Potential Value − Current Value

Platform anatomy

Five engines. End to end.

Each is a named, inspectable module — not a black box. The fifth is the conceptual upgrade: interactive what-if scenarios.

01 · INPUT

Input Engine

Quantitative data + a short, information-dense questionnaire. ~20 inputs total.

02 · SCORE

Scoring Model

Per-capital scores, overall quality, risk index, scalability index. Peer-relative percentiles.

03 · VALUE

Valuation Logic

V = EBITDA × Msector × SQF × GF. Calibrated against 14,999 Italian SMEs.

04 · ACT

Recommendation

Top 3 highest-impact actions over 24–36 months. Ranked by Return on Value (ROV).

05 · SIMULATE

Simulation Engine

Interactive what-if: how does my value move if I lift this lever by 20%?
