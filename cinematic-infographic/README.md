# VIP Cinematic Infographic

A standalone one-page cinematic explainer for the Value Intelligence Platform.

## Run Locally

```bash
cd cinematic-infographic
python3 -m http.server 8088
```

Open `http://localhost:8088`.

No install step is required. The page is plain HTML, CSS, and JavaScript, so it can be moved, hosted, or embedded independently from the main Next.js app.

## Files

- `index.html` - content structure and scenes
- `styles.css` - cinematic layout, depth, responsive design, and animation styling
- `app.js` - canvas background, scroll chapters, counters, peer universe, and simulator interactions
