# VIP — Web (Next.js 14)

The production Next.js codebase for **VIP — Value Intelligence Platform**.

> **Current state:** Phase 10 (the company-search pivot). Marketing site, per-company workspace, 20-question diagnostic, scoring pipeline, recommendation engine and simulation panel are all live. Demo mode is on (auth dormant).

## Run it

```bash
cd web
npm install
npm run dev          # http://localhost:3000
```

Default landing is the marketing scrollytelling page. The "Find a company" CTA (or the `/companies` route directly) goes into the app: search the AIDA cohort, open a company, run the diagnostic.

## Chrome & navigation

A shared **`<HomeLink />`** component (`components/chrome/home-link.tsx`) renders the VIP brand mark in the top-left of every route group and always links to `/`. From any page — marketing, auth, app — clicking VIP returns the user home.

## Architecture notes

**Animations are calm.** The earlier "cinematic mode" (Lenis smooth-scroll, GSAP scroll-triggered timelines, particle canvas, floating side-nav dots) has been removed. Scenes fade in via the `useReveal` IntersectionObserver hook + a `.reveal` CSS class. Informative motion only — number count-ups, the radar polygon morph, the capital weight bars.

**Two layout files for app vs. marketing.** The root layout hosts only fonts and the body shell. Each route group owns its own chrome (`HomeLink`, optional CTA, the in-app header), so the data-heavy app surface never pays for marketing decoration.

**Strict TypeScript.** `noUncheckedIndexedAccess` is on. Most array accesses use `.map` / `.forEach` to dodge it; a few well-known indices use non-null assertions.

**Design tokens.** All colors live in `globals.css` as RGB triples — Tailwind utilities like `bg-gold/30` work because the config maps every token to `rgb(var(--gold) / <alpha-value>)`.
