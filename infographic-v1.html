The problem

The strategic intelligence gap.

SMEs have data. They lack the translation from data into a quantified compass for the decisions that actually matter.

Data is everywhere

ERP systems, accounting software, CRMs — SMEs already produce more data than they realise. Storage isn't the constraint.

Insight is missing

Nobody translates that data into a clear picture of company value and the levers that drive it. Reporting describes; it doesn't decide.

Decisions in the dark

Investments, exits, growth bets — entrepreneurs commit capital and time without a quantified compass. Most rely on instinct, peer anecdotes, or a single advisor's view.

What it must do

Five capabilities. One platform.

The brief is sharp: VIP isn't a research artefact. It's a working tool with five non-negotiable jobs.

01

Estimate value

Credible methodology calibrated to real SMEs — not a naive EBITDA × multiple.

02

Score quality

Multi-dimensional scoring across the four capitals, normalised to peer group.

03

Surface drivers

Which factors create value. Which silently erode it. Both, transparently named.

04

Recommend actions

Top 3 highest-impact levers over 24–36 months, ranked by Return on Value.

05

Deliver simply

One dashboard. Designed for the entrepreneur — not the data scientist.

Core valuation formula
V = EBITDA × Msector × SQF × GF
EBITDA
Normalised 3-year average, smoothed for one-offs.
Msector
Sector multiple, discounted for illiquidity & SME-size.
SQF · 0.6–1.4
Aggregated 4-capital quality. Penalises fragility, rewards scalability.
GF · 0.7–1.5
Expected CAGR plus quality of growth (organic vs episodic).
Value Gap — the distance between today's value and the optimised potential the recommended actions could unlock. This is the platform's true differentiating insight.

Platform anatomy

Five engines. End to end.

Each is a named, inspectable module — not a black box. The fifth is the conceptual upgrade: interactive what-if scenarios.

01 · INPUT

Input Engine

Quantitative data + a short, information-dense questionnaire. ~20 inputs total.

02 · SCORE

Scoring Model

Per-capital scores, overall quality, risk index, scalability index. Peer-relative percentiles.

03 · VALUE

Valuation Logic

V = EBITDA × Msector × SQF × GF. Calibrated against 14,999 Italian SMEs.

04 · ACT

Recommendation

Top 3 highest-impact actions over 24–36 months. Ranked by Return on Value (ROV).

05 · SIMULATE

Simulation Engine

Interactive what-if: how does my value move if I lift this lever by 20%?
